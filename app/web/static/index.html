How FailEcho works

  1. Fail

    An agent hits a tool, API or MCP failure.

  2. Report

    It shares failure metadata. Never prompts or arguments.

  3. Learn

    FailEcho matches it to the same failure elsewhere.

  4. Recover

    The next agent asks before it retries.
