## Order

The order matters: `failecho-mcp` 0.2.3 on PyPI requires the new wrapper.

1. **PyPI, the wrapper first:**

       cd /root/agentwebsite
       .venv/bin/python -m twine upload dist/failecho_autoreport-0.1.7*

2. **PyPI, the MCP package:**

       .venv/bin/python -m twine upload dist/failecho_mcp-0.2.3*

3. **npm, the relay and proxy** (asks before publishing):

       ./scripts/publish_npm_relay.sh

4. **npm, the OpenCode plugin** (first publish claims the name):

       ./scripts/publish_npm_opencode.sh

5. **Optional:** refresh the MCP registry listing from `server.json`, now 0.2.3.
